# nextage-counting

本当のNEXTAGE祭の集計

## セットアップ

1. Google Apps Scriptを開き、APIをオンにする
2. `git clone ***`
3. `npm install`
4. `npx clasp login`でログイン

> [!CAUTION]
> claspコマンド実行時は`npx clasp ***`という形式にする

## 実行方法

GASのトリガーまたはGitHub Actionsから毎日AM 5時以降に以下を実行

```bash
npx clasp run runFetchAndWrite
```

10/1 AM5時以降、任意のタイミングで以下を実行

```bash
npx clasp runCompareAndWrite
```

ただし、引数は以下のとおりとする

```
d1: 本ネク投稿期間直前のデータを取得する。9/18投稿期間開始のため、"2026/09/18"を設定し、9/17までのボカコレ参加曲（REMIX除く）を対象とする
d2: 本ネク参加のすべてのデータを取得する。公には9/31 24:00までのマイリス数をもとに順位を決めると公表しており、"2026/10/01"を設定する
vocTags: 主に、ボカコレ参加曲のうち、本ネクに参加した曲のデータを取得するために使う。以下のように設定する（REMIXは後述のexcludeTagsで強制的に弾かれるので、ここで残しておいてもいいはず）
[
    "ボカコレ2026夏TOP100ランキング参加曲",
    "ボカコレ2026夏ルーキー参加曲",
    "ボカコレ2026夏ex",
];
honTag: 本当のNEXTAGE祭のタグ。"本ネク新世界";
topN: マイリス数の上位何動画を表示するか。20曲にマイリス相が与えられるが、念のため30を設定。
excludeTags: 集計時に除外するタグのリスト。["ボカコレ2026夏REMIX参加曲"]とする。これが必要な理由として、vocTagsにREMIXを書かなかったとしても、ボカコレに参加せず、新規曲で本ネクに参加した曲を「本ネクのタグがあって、かつボカコレのタグが一つもないもの」によって検索することにより、REMIXが含まれてしまうから
startTimeFrom: 本ネク投稿期間開始日をISO 8601形式で記述（形式は違ってもいいが日本時間であることを明記したい）。"2026-09-18T17:00:00+09:00"
startTimeTo: 本ネク投稿期間終了日。24時はエラーになるようなので0時を指定。"2026-09-20T00:00:00+09:00"; // 期間の終了日
```
