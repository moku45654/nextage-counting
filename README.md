# nextage-counting

本当のNEXTAGE祭の集計

## セットアップ

1. Google Apps Scriptを開き、APIをオンにする
2. `git clone ***`
3. `npm install`
4. `npx clasp login`でログイン

> [!CAUTION]
> claspコマンド実行時は`npx clasp ***`という形式にする

## 実行方法

GASのトリガーまたはGitHub Actionsから毎日AM 5時以降に動画データを取得する。

```bash
npx clasp run runFetchAndWrite
```

集計シートの作成は、10/1 AM 6時以降に以下を実行する。

```bash
npx clasp run runAggregateAndWrite
```

## 集計方法

処理は対象動画の抽出とマイリス数の比較の2段階で行う。

1. `2026/09/20`シートから対象動画の`contentId`を取得する。このシートは9/20 AM 6時に取得したデータ。
2. 本ネクタグが付いた動画のうち、ボカコレタグが付いた動画、または投稿期間内に投稿された動画を対象にする。
3. 対象動画について、`2026/09/18`シートのマイリス数を開始値、`2026/10/01`シートのマイリス数を終了値として差分を集計する。開始時点のシートに動画がない場合は、開始値を0として扱う。

主な設定値は以下のとおり。

```
candidateSheetName: 対象動画の抽出元。"2026/09/20"
d1: マイリス数の開始値を取得するシート。"2026/09/18"
d2: マイリス数の終了値を取得するシート。"2026/10/01"
vocTags: ボカコレ参加曲を判定するタグ。TOP100、ルーキー、REMIX、exの各タグを指定
honTag: 本当のNEXTAGE祭のタグ。"本ネク新世界2026"
topN: マイリス差分の上位何動画を表示するか。現在は30
excludeTags: 集計対象から除外するタグ。現在は空配列
startTimeFrom: 新規参加曲の投稿期間開始。"2026-09-18T17:00:00+09:00"
startTimeTo: 投稿期間の終了境界（この日時は含まない）。現在は"2026-09-20T00:00:00+09:00"
```
